# StarFolio · External archives

[中文](README.md) · [English](README.en.md)

An explicitly selected public collection, not a copy of the personal blog or a sync of the private library. Application: [StarDreamTech/StarFolio](https://github.com/StarDreamTech/StarFolio).

[Original public archive](https://github.com/cpython666/cpython666.github.io/tree/882c14a4821cbe3c583a75db3f5b8abdd0a2d188): 108 X posts and 1,501 replies visible when captured. The original JSON under `x/` is unchanged, including translation and attribution caveats. Images from 93 of 95 body-image URLs are available offline.

**Avatars:** 258 verified public profiles, appearing in 913 bylines. Dates record when a photo was observed, not when the post was written. Unverified bylines have no photo. `avatars/objects/` stores identical files once.

**Read offline:** download and unzip the repository, then open `index.html`. Keep the directory structure. No remote images or scripts load. Import into StarFolio 0.2.2+ with `folio import-collection <directory>`, or enrich an existing shelf with `folio import-avatars <directory>/avatars`. Original authors retain their rights.
